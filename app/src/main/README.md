# TODOL

# 计算机技能大赛概述

    TODOL是一款悬浮窗记事App，由Kotlin语言开发
    我之所以选择Kotlin而不是java是因为Kotlin开发安卓是全球趋势，且其语法简单，流程更安全
    基本功能
        记录笔记（暂时不支持多媒体）（有待加密数据库）
        定时提醒（提前十分钟振动提醒）
        查看历史笔记（UI有待完善、数据有待扩充）
        导出笔记为图片（有待完善，目标是生成思维导图）
    程序特点
        实用性强；
        体积小巧，随开随用
        使用本地SQLite存储数据，不与服务器交互，保护用户数据安全
    面向用户
        适用于所有需要快速即时记录信息、笔记、灵感的人群
    程序意义
        极大地简化了笔记记录过程，显著降低记录成本——我准备依次为题写一篇实证论文
        丨------------------------------> 笔记重要程度阈值 
        只有当 笔记重要程度 > 记录成本 时我们才有动力记录笔记
        十年前记事要随身携带一支笔和一个笔记本
        五年前记事要打开手机上的备忘录
        今天记事只需要随时随地点一个按钮
        随着记录成本降低，越来越多的细微灵感得以记录，也就逐渐养成了经常思考的习惯

        从2023年5月20日到今天我没有一天不使用TODOL，平均每天记录十条笔记，今天的笔记有
            学习团队管理工具，晚上七点歌手大赛，打印四六级准考证，下周三和高中同学见面，黑暗森林法则
